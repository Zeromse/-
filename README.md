# 次生预案 · 交互式活动档案

直接双击 index.html 即可使用，也可运行 `node server.cjs` 后访问 http://127.0.0.1:4408 。无需安装前端依赖。

原生 HTML、CSS、JavaScript 实现，支持桌面和移动端。包含资源采集模拟、策略升级、战备任命、关卡选择、影像筛选、图片查看和原视频播放。支持键盘切换 tabs、Escape 关闭弹窗及减少动画偏好。

assets 中的截图及视频来自提供的「次生预案」活动.mp4。资源设备主视觉是原始帧裁切，未生成额外设定。所有演示数值、策略名称、匿名编组及节点连接均在界面中标注。演示状态仅保留至刷新，不连接真实账号。原视频日期为历史活动记录。

文件：index.html（结构）、styles.css（样式）、app.js（交互）、assets/（本地素材）、server.cjs（可选本地服务器）。
